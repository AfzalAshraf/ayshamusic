# Durable lessons from the failed Android playback iterations

This is repository memory, not a claim of permanent model training or authority.
Follow current user scope; preserve Rust acquisition/Telegram, Media3 audio-only,
the supplied launcher artwork and the dedication. Do not request secrets in chat.

1. Record the screenshot's engine, compiled source, exact error and playback
   stage. Code10 and11 physically failed; never turn their green builds into a
   working-playback claim. Build11/source10a46e6 now has both403 and302 evidence.
2. A metadata URL is not media-read acceptance. A buffer's first second is not
   uninterrupted audio. Check first, tail/index, spaced later ranges and strict
   response bounds. No full-file download solely to manufacture a pass.
3. Source302 may be a CDN handoff: preserve Range/identity across at most3 HTTPS
   googlevideo redirects, reject credentials/private/non-CDN/downgrade targets
   BEFORE sending, preserve signed query bytes, detect loops and keep one12s
   operation deadline. Never automatically follow arbitrary redirects.
4. Do not discard a validated initial block and fetch it again. Cache at most
   first/tail64KiB and fail preparation before Play if the index cannot be read.
   Still surface later-source errors; the probes do not prove whole-file access.
5. Source403 may require player/n transformation or normal source eligibility;
   do not call it a codec bug or assume headers/client versions fix it. A fuller
   extractor that returns AAC metadata with empty URLs is not a playback solution.
   Do not bypass bot/sign-in/access gates or substitute a hosted/Python helper.
6. Research first from pinned upstream code; distinguish current compatibility
   evidence from a PR's claims. Do not silently add a Java extraction boundary.
7. Verify actual Media3 decoding/control behavior on Android separately from Rust
   source fixtures. An emulator tone is not YouTube/phone-speaker acceptance.
8. Keep routine CI offline for source access. Explicit live diagnostics need
   host/bytes/request/time limits, safe classifications, one gated invocation and
   evidence inspection before any further run. Signed URLs/provider bodies and
   credentials must not appear in logs/artifacts.
9. User removed the Rust Audio Android APK. Build/upload Media3 only; do not
   remove the Linux Rust player or Rust acquisition/Telegram by implication.
10. Append each new reproducible failure, corrective test, run/artifact identity
    and acceptance limit to docs/LOCAL_QA_LEDGER.md. Improve this skill when a new
    concrete lesson appears; never claim merely adding skills fixes playback.
